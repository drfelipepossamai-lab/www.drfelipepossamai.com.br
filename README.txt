SITE DR. FELIPE ROSA POSSAMAI

Arquivo principal: index.html

COMO PUBLICAR
1. Envie a pasta para uma hospedagem de site estático (Hostinger, Vercel, Netlify, GitHub Pages etc.).
2. Aponte o domínio drfelipepossamai.com.br para a hospedagem.
3. O site não possui checkout ou pagamento: o pedido é montado no navegador e o último passo abre o WhatsApp com os itens e o valor estimado.

OBSERVAÇÕES
- O layout foi construído inspirado na lógica de navegação por categorias e cards de uma plataforma de pedidos, sem reproduzir marca, logo ou identidade visual do iFood.
- Foram usadas as imagens oficiais fornecidas no briefing por URL remota (logo e foto profissional).
- Valores dos exames individuais foram preenchidos com base nos valores visíveis no site ClinicASSO consultado em 18/09/2026, respeitando os valores informados pelo contratante para Consulta/ASO e combos.
- Antes de publicar, confirme os valores, disponibilidade dos exames, domínio e o número oficial do WhatsApp.
